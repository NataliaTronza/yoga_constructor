# Дихання — як поставити на телефон

У папці шість файлів. Вони мають лежати **разом, в одній теці** — інакше не буде ні іконки, ні офлайну.

```
index.html
manifest.webmanifest
sw.js
icon-192.png
icon-512.png
icon-512-maskable.png
```

## Спосіб 1 — встановити як застосунок (рекомендую)

Установлення вимагає адреси `https://`, тому файли треба один раз десь покласти. Підійде той самий GitHub Pages, де вже живуть уроки.

1. Створи репозиторій, наприклад `yoga`, і заванаж туди всі шість файлів.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. За хвилину сторінка буде за адресою `https://<твій-нік>.github.io/yoga/`.
4. Відкрий цю адресу в Chrome на телефоні. Знизу з'явиться пропозиція встановити, або кнопка «Встановити» у шапці, або меню ⋮ → «Додати на головний екран».

Після цього застосунок стоїть окремою іконкою, відкривається на весь екран без адресного рядка і **працює без інтернету** — усе закешовано.

На iPhone: Safari → кнопка «Поділитися» → «На екран «Додому»». Кнопки «Встановити» там немає, це особливість Safari.

### Коли міняєш файли

Телефон тримає стару копію в кеші. Щоб оновлення приїхало, підніми версію в `sw.js`:

```js
const V = 'dyhannia-v2';   // було v1
```

## Спосіб 2 — просто відкрити файл

Скинути `index.html` на телефон і відкрити з «Файлів» через Chrome. Працює одразу, але без іконки на екрані, і браузер може час від часу чистити збережені послідовності. Для щоденного користування спосіб 1 надійніший.

## Спосіб 3 — справжній APK

Якщо хочеться саме файл-установник: сайт **PWABuilder** бере готову адресу з кроку 1 і збирає з неї підписаний `.apk`, який ставиться з файлу. Кодити нічого не треба, але без кроку 1 не обійтися — APK усередині все одно загортає цю саму сторінку.

## Де зберігаються дані

Усе — послідовності, треки, журнал практик — лежить у пам'яті браузера на цьому пристрої. Нічого нікуди не надсилається. Перенести на інший телефон: **Музика → Резервна копія → Зберегти у файл**, і на новому пристрої «Відновити з файлу».

## Звук

Браузери не дають вмикати звук самі — перший дотик до екрана і є дозволом. Тому тло вмикається з натисканням «Почати», а не раніше.
